# Bookstore Management System – REST API

## Project Description
This project is a Bookstore Management System developed using Java and Spring Boot. It provides REST APIs to manage books, users, orders, and inventory.

## Technologies Used
- Java
- Spring Boot
- MySQL
- Spring Data JPA
- Spring Security
- JWT Authentication
- Swagger UI

## Main Features
- Add, view, update, and delete books
- User registration and login
- JWT-based authentication
- REST API documentation using Swagger

## API Testing
